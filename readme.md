
  **Jev-vs-engine chess loop.**
  
  **Requirements:**
    - Node.js 20+
    - TYPESAFE_API_KEY set in the environment
    - npm install

    
  **Run with:**
  npm start

  
  Jev plays White and chooses from moves generated by js-chess-engine.
